# Written guidance and engine evidence

This bundle imports reviewed design documents from an immutable Impeccable commit. It does not contain its launcher, binaries, hooks, installation configuration, browser injection, live-edit server or context/storage engine. Nothing in a copied command example authorizes executing an absent runtime or installing one.

The current workflow can use normal source inspection, browser rendering and the project's existing checks to apply Operate/Read principles, polish triage, typographic hierarchy, grouping and clear copy. Call the result an **Impeccable-guided design review** and name the evidence actually gathered.

The full upstream commands have additional requirements:

| Upstream workflow | Evidence that written guidance alone cannot establish |
| --- | --- |
| `context` | The engine's resolved project, surface and configuration output. |
| `audit` | Bundled detector findings and verification, plus the engine's saved report workflow. |
| `critique` | The specified independent assessments, an actual detector attempt, relevant browser/overlay accounting and saved critique snapshot. |
| `layout` / `typeset` | Their written assessment is usable here; their scoped detector steps require the engine. |
| `polish` | Manual path and visual review are usable. Claim prior-snapshot handling, hook output or detector checks only when those operations genuinely ran. |

If an engine capability becomes necessary, inspect an independently provisioned, version-pinned runtime under the user's authorized scope. Establish what will run and where it will write before using it. Do not install or enable upstream hooks, binary downloads or live Apply as a side effect of ordinary UI work. Existing session authorization takes precedence over repeating permission questions.

The source documents preserve upstream scoring and workflow examples for comparison. Do not publish a native-engine audit score, a detector rule count, a live overlay claim or an upstream workflow-completion claim from a manual review. Identify limitations directly and continue useful work that does not depend on the missing capability.
