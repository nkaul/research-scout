## Implementation and validation

- Python/API/provider code is under `backend/src/research_scout/`, with Python tests in `backend/tests/`, utilities in `backend/scripts/` and fixture/evaluation assets in `backend/fixtures/` and `backend/evals/`. The uv project is `backend/pyproject.toml` + `backend/uv.lock`, requires Python 3.13 and uv `>=0.13.8,<0.14`, and uses `backend/.venv`. Frontend code, browser tests and browser tooling live under `frontend/`; system design remains under `system-design/`.
- From the repository root, use `uv sync --project backend --locked`, then `uv run --project backend --locked python backend/scripts/dev.py` to launch owned independent services. Keep repository-root `.env` and `.scout` state/credentials/caches/model ledgers in place; moving code must not reset them. The earlier root `.venv` is not the active backend environment. Ignored uv and Node bootstraps are available at `.tools/uv/bin` and `.tools/node/bin`.
- The local encoder is an optional uv extra. For an encoder-enabled environment, consistently add `--extra encoder` to both `uv sync` and `uv run`, including test/tool commands; otherwise uv may synchronize it out. Fixture-only validation can omit the extra. Never infer authorization to download model artifacts or make live calls from an environment sync.
- Default fixture mode still executes real Deep Agents graphs, application MCP, service HTTP and browser SSE. Never describe fictional provider records or scripted model responses as live research/quality evidence.
- Research Scout ports are frontend 3100, core 8100, paper/video/access providers 8111–8119 and the Hugging Face dataset provider 8120 and GitHub repository provider 8121. The [provider expansion checkpoint](system-design/provider-expansion-2026-11-09.md) defines the current eight-service/six-discovery roles and Unpaywall access configuration. GitHub Manager may occupy 3000; do not attach tests to it or terminate unrelated processes.
- Run `uv run --directory backend --locked pytest -q`, `uv run --directory backend --locked ruff check src tests scripts`, and the synthetic eval command in the root README for relevant backend changes. Frontend checks run from `frontend/`: `npm run typecheck`, `npm run build` and Playwright browser acceptance under `frontend/tests/browser/`. The explicit actual-backend browser case requires `SCOUT_BROWSER_INTEGRATION=1` and running fixture services; it must fail rather than silently skip when explicitly enabled.
- Keep provider SDKs/access/cache/attempt journals in independently launched single-provider services. Keep app eligibility/rank validation, canonical DOI grouping and human authority in the core. Automatic fan-out to the recorded eligible source plan is authorized; do not silently switch outside that plan or blend fields across provider observations.
- Single-owner atomic JSON is the implemented local persistence; production database/authentication/hosting remain unselected. Read the status record before claiming recovery or model-cost guarantees.
